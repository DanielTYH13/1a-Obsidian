*Key Concepts:*
___

For an n bit adder, we can add xor gates to the inputs of one of the arguments such that:

Polarity bit = 0 $\implies$ Input bits unchanged $\implies$ Addition
Polarity bit = 1 $\implies$ Input bits inverted $\implies$ 1's complement subtraction.

Moreover, we can add 1 to the carry, determined by the polarity bit, to turn it into 2's complement subtraction, by the conversion process of [[2's Complement]].
