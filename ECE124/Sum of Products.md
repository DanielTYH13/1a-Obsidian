*Key Concepts:*
___

The sum of products is a method of turning a truth table into a boolean function.

It functions by taking the union of each possible case where the function is true. 

---

Since the sum of products uses the AND operator to define truth cases, each individual term is true if and only if all arguments are true. 

This prevents all false positive cases.
