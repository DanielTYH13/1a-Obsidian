*Key Concepts:*
___

A flip flop is a form of memory that is edge reactive. Ie, state can only be changed when the clock level changes. 

It is composed of two basic latches. The functionality works this way (For a negative flip flop):

Clock HIGH -> value loaded into latch one, latch two is not enabled.
Clock LOW -> value loaded into latch two, no more values accepted at latch one. 

For a positive:

Clock LOW -> Value loaded into first, second unresponsive,
Clock HIGH -> Value loaded into second, first unresponsive.
