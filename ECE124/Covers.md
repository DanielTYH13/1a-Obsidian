*Key Concepts:*
___

A cover is a set of implicants which are equal to the function. That is it. 

It is a formal definition of the groups in K-maps. 

---

Of all covers, the ones which the minimum cost implementation are:

1. Covers consisting of Essential Prime Implicants only
2. Covers consisting of Prime Implicants only

An informal intuition is given:

The definition of a prime implicant is an implicant with the maximal freedom over a given set of minterms, and thus the highest "coverage" of a k-map. This also means it has the least number of terms.

Thus, an implementation consisting of only minterms has maximal coverage with minimal cost. 

Something to think about:

If you were given three prime implicants, one which can be constructed by two of the others, in which cases is it more optimal to choose which sets of prime implicants?
