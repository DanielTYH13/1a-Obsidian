*Key Concepts:*
___

For any boolean function of n variables, a minterm is a product which includes all n variables. 

It is called a minterm because it is true for only one condition (Allow the minimum flexibility).
- By definition, the minterm of any given input pattern should be 1 for that input pattern. 

In circuit synthesis, sums of minterms allow you to take the union of all true cases ([[Sum of Products]])

Minterms are the negation of [[Maxterms]] by D'Morgan's law.
