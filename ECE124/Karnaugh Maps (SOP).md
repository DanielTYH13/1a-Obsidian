*Key Concepts:*
___

K-maps are coordinate based representation of truth tables. They are a visual tool in recognizing simplification patterns in boolean functions.

You can group vertically and horizontally, but only in groups of $2^n$
- This is because you can only eliminate an irrelevant variable from its two states. 

For K-maps above 2 variables, the gray's code is used to list the variable values. 
- This is so that if any two boxes are equal in truthness and are adjacent, you know that there exists only one irrelevant variable between those two that you can eliminate.

You can group variables that are on the sides of k-maps.

For 5 variable k maps, you just imagine 2 4 variable k-maps, where x_5 = 0 for one and x_5 = 1 for the other.
