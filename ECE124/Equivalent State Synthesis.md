*Key Concepts:*
___

Equivalent state synthesis is similar to [[Unstable State Synthesis]], but on top of using unstable states (Which direct towards the correct end state, but has no functionality themselves), they add equivalent functionality to the current state such that any change midway during the transition is still considered. 

Other than that, it is quite literally equivalent. 

---
Corollary: For the n = 2 case, we have that we only need one equivalent state. For n = 3 case, we need 2, etc.
