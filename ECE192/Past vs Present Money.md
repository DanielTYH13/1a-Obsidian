*Key Concepts:*
___

We assert that money, due to investment, will always grow with some interest from now to the future. 

In some sense, if we factor in time, these sums of money are equal. However, absolutely, they are different by some scaling factor, which we call interest. 

We have that P for present value, F for future worth:

$F = P(1 + i)$
$P = \frac{F}{1+i}$

---
Cash Flow Equivalence

This concept is formalized by the equivalence of cash flows. 

Two values of money, $P_{t}$ and $F_{t + n}$ are equivalent with respect to interest over time from a base time t if 

$F_{t + n} = P_{t}(1 + i)^{n}$

And similarily:

$P_{t}$ and $F_{t+n+m}$ are equivalent if $F_{t+n+m} = P_{t}(1 + i)^{n+m} = F_{t+n}(1 + i)^m$

Note this only works because $F_{t+n}$ is given based on $P_{t}$ and is assumed to be equal to $P_{t}$
