*Key Concepts:*
___

For AC current, we have that the voltage can be represented as: $V(\omega t + \phi) = cos(\omega t + \phi)$

By euler's identity, we also ahve 

$e^j(\omega t + \phi) = cos(\omega t + \phi) + jsin(\omega t + \phi)$

So the function for the voltage can be expressed as the real part of the imaginary function in polar coordinates. This makes many calculations much easier, for example finding current in an RC circuit (In the slides #TODO).
