*Key Concepts:*
___

The Root Mean Square of a given signal f(t) is given as:

$\sqrt{\frac{1}{T}\displaystyle \int^{t_{0} + T}_{t_{0}}(f(t))^2dt}$

The process is given as: 

1. Square every value (every differential element)
2. Take the sum of every value and divide by the number of elements
3. Take the root of the sum.

What this does is:

1. Convert all values to the positive domain 
2. Find the average value
3. Normalize the square out. 

It is like the dot product. Unintuitive process, but turns out to be a computational convenience.
