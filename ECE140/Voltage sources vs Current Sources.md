*Key Concepts:*
___

Voltage sources and current sources are as they sound, they provide voltage and current, respectively.

Voltage sources in parallel:
- This realistically is not possible, and theoretically is not possible if the voltages are different. 
- This is because :: The voltage different between each node will be non-zero, thus causing current to flow through the zero resistance wire. This will cause a short circuit:
	- ![[Pasted image 20260525155557.png]]

Current sources in series:
- This again is not possible, due to KCL. 
- Intuitively, if n currents are flowing into a node, how is it possible that more or less current can flow out? Assuming that that all current must go out.
