*Key Concepts:*
___

Given a Thevenin circuit, you need to apply a test voltage to find the resistance. Ie, if V_in was at the nodes, what would be the current passing through the circuit?

An easy way of doing this is by using Node analysis, where you find the node at the voltage in: This will give you an equation that relates I_in to V_in. 

Then, use Node analysis to find I_in wrt to only V_in (Ie through substitution), then divide V_in by I_in, which will cancel out all V_in within I_in and give you a Thevenin resistance.
