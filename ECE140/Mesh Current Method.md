*Key Concepts:*
___

The Mesh Current Method is where you imagine a current moving clockwise around each atomic loop. 

This is done to create a system of equations (Using KVL) for each loop, then to solve for the current.

---
In reality, there is no actual "negative current". It's just an mathematically correct abstraction.

---
It is a circuit analysis technique that just makes it easier to solve for current with multiple sources.
