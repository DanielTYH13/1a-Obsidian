*Key Concepts:*
___

An ideal voltage source has free current - ie the current can be whatever it needs to be in order for KCL to be satisfied.

Since to achieve this, we need to satisfy $V = IR$, and thus we have a *static* resistance at any voltage and required current. It is required to make the distinction that this is not a dynamic resistance, as it will change to preserve KCL (The component does not have a fixed resistance R, rather it changes to accomodate for errors).
