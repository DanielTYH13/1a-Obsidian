*Key Concepts:*
___

Ratio test is best used when a series appears to have a lot of terms which have convenient multiplication and division properties. Examples include exponenetials and factorials. Oftentimes this will leave a well known limit or a limit solvable by reciprocal.

In other words, if you can imagine multiplying a term by its inverse, and it looks to work out very well, then ratio test might be useful. 

In fact, ratio test should immediately come to mind when working with factorials, as they are hard to define but easy to cancel out when you have immediately preceding terms on the numerator / denominator.

---

Ratio test is similar to the LCT in that it utilizes division to simplify. The advantage of the ratio test is that you do not need to know the behavior of the function that you are simplifying in order to use it. This is helpful for hard to define functions like the factorial.
