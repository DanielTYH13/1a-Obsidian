When integrating volume, we wish to fina certain volume given in units cubed. We may sometimes find it useful to change variables to spherical or cylindrical, or any other non linear system.

IN these cases, a change in the differential elements, du, dv, etc. (Ex. $d\phi d\theta dr$) do not correlate directly to the real volume, in the desired units. Thus, we must add a jacobian so we can scale between changes in angle, to changes in volume. This is what the jacobian is defined as (scaling changes in one variable space to changes in another variable space).
