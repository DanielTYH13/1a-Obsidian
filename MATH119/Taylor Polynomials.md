*Key Concepts:*
___

Taylor polynomial is an approximation for a function at a point (As opposed to function interpolation, which approximates over many points). Its precision can be increased to infinity, by Weierstrass Theorem (As long as the function is infinitely differentiable). 

It is given by many terms of increasing derivatives:

$T_{n,a} = \displaystyle \sum^n_{k=0}\frac{f^k(a)}{k!}(x-a)^k$

The Taylor polynomial accuracy improves over derivatives, whereas interpolation accuracy improves over points. 

---
Taylor Polynomials are unique (Ie there does not exist two taylor polynomials for a function defined at the point)
