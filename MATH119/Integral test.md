*Key Concepts:*
___

For a sequence $a_{k}>0$ for all k, and function $f(k) = a_{k}$ for all positive integers k and is positive, decreasing, and continous on the interval $(k, \infty)$.

Then $\displaystyle \lim_{n = \infty} \sum^n_{k = 0} a_k$ is convergent if and only if $\displaystyle \lim_{n \to \infty} \int^n_{0} f(k) \text{d}k$
