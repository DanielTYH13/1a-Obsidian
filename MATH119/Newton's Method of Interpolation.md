*Key Concepts:*
___

Newton's method of interpolation is given as:

$x_{n+1} = x_{n} - \frac{f(x_n)}{f'(x_{n})}$

It works by finding the approximate root for a given estimate, and since that approximate root should be close to the real root, we then repeat using that "refined" guess.

Each iteration reduces the error until we are extremely close. Oftentimes this method provides correct roots up to 7 decimal places with very few iterations.
