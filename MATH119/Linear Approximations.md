*Key Concepts:*
___

Recall from [[Tangent Planes]] that the tangent plane at a point x', y' is

$z = f(x', y') + f_{x}(x', y')(x - x')+ f_{y}(x', y')(y - y')$

For points x, y near x', y', this is an approximation of f(x, y). We can find the difference, $\Delta f(x, y) = f(x', y') - f(x, y)$ as:

$\Delta f(x, y) = f_x(x-x') + f_y(y-y')$.

Oftentimes, you will see this written as:

$df = f_{x}dx + f_{y}dy$

Simply to encapsulate the idea that the approximation's error approaches 0 as $\Delta x$, $\Delta y$ approach 0. Thus, we start with this form then switch to using $\Delta$ instead.
