___

We would like an easy way to construct polynomials that fit a given set of points, samples at possible inequal points. 

We can create such a function

$f(x) = \displaystyle \sum^N_{n = 0} \frac{(x - x_{0})(x-x_{1}) \cdots (x - x_{n-1})(x-x_{n+1})\cdots (x-x_{N-1}) (x-x_{N})}{(x_{n} - x_{0})(x_{n}-x_{1}) \cdots (x_{n} - x_{n-1})(x_{n} -x_{n+1})\cdots (x_{n}-x_{N-1}) (x_{n}-x_{N})}$
