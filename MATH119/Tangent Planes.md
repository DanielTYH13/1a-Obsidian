*Key Concepts:*
___

The objective is to find a plane that lies on (x, y, f(x, y)) and is tangent wrt both x and y. 

Given the objective, we need to know that the line reduction of the plane along the y = y' and x = x' planes have slopes which are the derivatives of f(x,y) wrt to x, y respectively.

The equation of a plane is given by z = z' + A(x - x') + B(y - y'). 
- Set y = y': z = z' + A(x-x')
	- It can be inferred that therefore $A = f_{x}(x',y')$
- Set x = x': z = z' + B(y - y')
	- It can be inferred that therefore B = $f_{y}(x', y')$

Therefore, the equation of a tangent plane is

$z = z' + f_{x}(x', y')(x-x') + f_{y}(x', y')(y-y')$
