*Key Concepts:*
___

```ad-definition

$S \in \mathbb{R}$ is an interval if and only if for every $x, y\in S$, if $x \le z \le y$, then $z \in S$.

```

An interval is a continuous segment of the real number line. It is a type of [[Set]].

Closed interval: $[x, y]$
Closed intervals include their own bounds. 

Open interval: (x, y)
Open Intervals exclude their own bounds.

```ad-example

[[Proof by Contradiction]] that the null set ($\phi$) is an interval:

By definition, for all x, y in $\phi$, if $x \le z \le y$ and $z \in \phi$ (p) implies that $\phi$ is an interval (q). The contraposition is that there exists x, y in $\phi$ such that $z \not\in \phi$ ($\neg p$). 

$p$: $(\forall x : x \in \phi, \forall y : y \in \phi, \forall z : x \le z \le y) \implies z \in \phi$
$\neg p$: $(\exists x : x \in \phi, \exists y : y \in \phi, \exists z : x \le z \le y ) \implies z \not\in \phi$

Since p is true, and $\neg q \implies \neg p$, then q is true.

```
