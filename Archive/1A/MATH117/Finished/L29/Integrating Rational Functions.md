*Key Concepts:*
___

- Integrating rational function takes rote steps:
	1. Check if in either form:
		1. $\displaystyle \int \frac{1}{x} = \ln|x| + C$
		2. $\displaystyle \int x^n = \frac{x^{n+1}}{n+1} + C$
	2. Check if u sub in the denom helps
	3. Check if trig sub in the denom helps
	4. Check if in form:
		1. $\displaystyle \int \frac{1}{x^2 + 1} = \tan^{-1}(x) + C$
	5. If all above fails, then use partial fraction decomposition or long division if the degree of the numerator is equal to or greater than the degree of the denominator (the rational fcn is improper)
	6. Make sure to fully factor the denom
	7. Repeat from above process
