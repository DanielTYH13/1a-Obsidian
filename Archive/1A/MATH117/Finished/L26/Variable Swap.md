*Key Concepts:*
___

- In some cases, upper/lower bound functions will swap. In these cases, it may be useful to change variables - effectively flipping the graphs:
	- ![[Pasted image 20251210195318.png|450]]

- In other words, given functions f(x), g(x), then to flip, integrate as so:
	- $\displaystyle \int^{y=b}_{y=a}(f(y)-g(y))dy$. 
		- You can convince yourself that f(y) and g(y) should be the inverses of f(x) and g(x) as the following:
			- Given the inverse gives an x value for any given y,
			- The new "height" is the x value for every given yh  value on the y axis. 
			- thus, take the inverses, and use y as the independant variable
			- Integrate w.r.t y.
