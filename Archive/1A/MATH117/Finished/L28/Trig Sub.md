*Key Concepts:*
___

- We can sub x as a trig function, and since we can represent trig functions as ratios of triangles, we can later represent the function in terms of x.

- Trig sub often looks worse before it gets better.

Trig subs:
- $\sqrt{a^2 - x^2}$
	- ==$x = a\sin(\theta)$==
	- ==$a^2 - a^2\sin^2(\theta) = a^2cos^2(\theta)$==
- $\sqrt{a^2 + x^2}$
	- ==$x = a\tan(\theta)$==
	- ==$a^2 + a^2\tan^2(\theta) = a^2sec^2(\theta)$==
- $\sqrt{x^2 - a^2}$
	- ==$x = a\sec(\theta)$==
	- ==$a^2\sec^2(\theta) - a^2 = a^2\tan^2(\theta)$==
