*Key Concepts:*
___

- For the vectors $\vec{x}_1, \vec{x}_{2}, \ldots , \vec{x}_{k}\in \mathbb{R}^n$ and scalars $c_{1}, c_{2}, \ldots , c_{k} \in \mathbb{R}$, the transformation $f(\vec{x})$ is a linear transformation $\iff$
	1. $f(\vec{x}_{1} +\vec{x}_{2} + \cdots + \vec{x}_{k}) =f(\vec{x}_{1}) + f(\vec{x}_{2}) + \cdots + f(\vec{x}_{k})$
	2. $f(c\vec{x}) = cf(\vec{x})$
	3. When trying to prove linearity, both of the above conditions are encapsulated in the following: $f(c_{1}\vec{x}_{1} + c_{2}\vec{x}_{2} + \cdots + c_{k}\vec{x}_{k}) =f(c_{1}\vec{x}_{1}) + f(c_{2}\vec{x}_{2}) + \cdots + f(c_{k}\vec{x}_{k})
- Corrolary: If $f(\vec{x})$ can be represented as a [[Archive/1A/MATH115/3./3.1/Matrix Transformations]], it is immediately a linear transformation.
