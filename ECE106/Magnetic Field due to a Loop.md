*Key Concepts:*
___

For N loops of a current carrying wire (Ie, zero thickness, assumed to be stacked with 0 difference in height):

$\vec{B} = N\frac{\mu_{0}}{2} \frac{IR^2}{(z^2 + R^2)^{\frac{3}{2}}}$

This is because magnetic fields are additive. 

---

The field at the axis of the loop is given as:

$\vec{B} = \frac{\mu_{0}}{2} \frac{IR^2}{(z^2 + R^2)^{\frac{3}{2}}}$

For the magnetic field at the center of the loop, ie when z = 0:

$\vec{B} = \frac{\mu_{0}}{4\pi} \frac{IR^2}{(R^2)^{\frac{3}{2}}}$
$\vec{B} = \frac{\mu_{0}}{4\pi} \frac{IR^2}{R^3}$
$\vec{B} = \frac{\mu_{0}I}{2R}$

For N loops, then 
	
$\vec{B} = \frac{\mu_{0}NI}{2R}$
