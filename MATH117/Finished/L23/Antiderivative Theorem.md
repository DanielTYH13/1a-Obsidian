*Key Concepts:*
___
 
- if $F(x), G(x)$ are both antiderivatives of the function $f(x)$, then there exists constant $C \in \mathbb{R}$ s.t. 
	- $F(x) + C = G(x)$.
- Ie, since integration and derivation undo each other, and derivation eliminates constants, then integration must have an unknown constant. 
- Ie, integration only tells you how the area under a function increases wrt x, not its total area.
