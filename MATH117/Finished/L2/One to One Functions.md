*Key Concepts:*
___
**Definition**:

- "1:1" (One to One) functions, f(x) = y, have no two pairs of (x, y) with the same x or y values. 
	- In other words, the same two values never appear twice within a value output pair. 

---
**Horizontal Line Test**

- A function that passes the HLT (Horizontal Line Test) $\iff$ 1:1.
