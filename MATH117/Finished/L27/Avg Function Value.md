*Key Concepts:*
___

- The expression for the average value of a fcn is given by:
	- $f_{avg}= \frac{1}{{b-a}}\displaystyle \int^b_{a}f(x)dx$

- The derivation of this is as follows:
	- $f_{avg}= \frac{\displaystyle \sum^n_{i=1} f(x_{i})}{n}$
	- Given that $\Delta x= \frac{b-a}{n} \implies n = \frac{b-a}{\Delta x}$
	- Subbing:
	- $f_{avg}= \frac{\displaystyle \sum^n_{i=1} f(x_{i})}{\frac{b-a}{\Delta x}}$
	- $f_{avg}= \frac{\displaystyle \sum^n_{i=1} f(x_{i}) \Delta x}{b-a}$ taking the limit:
	- $f_{avg} = \displaystyle \lim_{n\to \infty} \frac{1}{{b-a}}\sum^n_{i=1}f(x_i)dx$
	- $f_{avg} = \frac{1}{{b-a}} \displaystyle \int^b_{a}f(x)dx$.
