- Preread [[Reimann Sums]]

- Due to the cumbersome notation of Reimann Sums, we use integral notation:
	- $\displaystyle \int_{a}^{b}f(x)dx$, called the Definite Integral
		- Note that the variable x is a dummy variable.
			- In other words, you can use any variable name here, regardless of the function's variables itself. This is because the variable "replaces" all of the variables inside the function
