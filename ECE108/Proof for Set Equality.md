*Key Concepts:*
___

A set A is equal to another set B if and only if they are both subsets of each other.

A visual intuition can be constructed by venn diagrams. 

---
Proof: 

Premise: $A = B \iff A \subseteq A \wedge B \subseteq A$

$(A = B) \iff (x \in A \iff x \in B)$
$(A = B) \iff ((x\in A \implies x \in B) \wedge (x \in B \implies x \in A))$
$(A = B) \iff ((A \subseteq B) \wedge (B \subseteq A))$
