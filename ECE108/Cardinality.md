*Key Concepts:*
___

A function's cardinality is defined by the ability to "label" each element with a natural number. 

Ie, we have that $|S| = n, n \in \mathbb{N}$ if and only if we can construct a bijective function f from S to $\mathbb{N}_n$, where $\mathbb{N}_n$ is the set of natural numbers up to and including n.

Since f is injective, then we "label" each of the elements with a unique natural number. Since f is surjective, then there are exactly n labels, and thus exactly n elements in f.
