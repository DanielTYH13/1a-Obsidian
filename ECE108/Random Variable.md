*Key Concepts:*
___

For a sample set S, which contains events s, then a random variable is a function $X(s) S \to \mathbb{R}$.

In other words, it assigns a numeric value for every event. 

In practical terms, this is often the "reward" or "return". For example, winnings when you win a coin toss.
