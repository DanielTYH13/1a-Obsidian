*Key Concepts:*
___

A set is a collection of elements. There are a few restrictions to the definition of an element, and what they are.

---
They must be unique.

A set cannot contain more than one instance of the same element. All are unique. This prevents sets which infinitely many equivalent sets, element wise. 

---
They do not have order.

A set is the same whether it is {a, b} or {b, a}. There is no notion of order in a set (of its fundamental elements, see [[Ordered Pairs]]).

---
They must have a defined universal set. 

This prevents paradoxes, and recursive sets. 

For example, consider the set of all sets that do not contain themselves. Does this set contain itself?

$S \notin S \implies S \in S$
