*Key Concepts:*
___

If we have set builder notation, where there is a specified superset for the set and a condition which specifies the subset, then we can avoid a lot of paradoxes. 

The logical notation for sets of this form is given as follows:

$S = \{x \in A|p\}$
$x \in S \implies x\in A \wedge p$
$x \notin S \implies x\notin A \vee \neg p$

Thus, for elements which would cause paradoxes, we can exclude them from the superset, and thus maintain logical integrity.
