*Key Concepts:*
___

If you have a set of n and you choose k with replacement, then it is:

$\displaystyle \sum^k_{i=1} \binom{n}{r}$

---

You can imagine that for any case, you will necessarily select 1, 2, 3, ..., r members only since there is replacement. Then, you can imagine "splitting" up the choose set into partitions, for which each of the members must occupy. It does not matter the size of the partitions, only that you can partition it such that each partition is assigned to only one member. Then, since there are no more duplicate assignments, the problem becomes an unordered selection without replacement.
