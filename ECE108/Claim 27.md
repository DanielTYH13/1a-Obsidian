*Key Concepts:*
___

There exists an injection from A to B if and only if there exists a surjection from B to A. 

Equally, there exists a surjection from A to B if and only if there exists an injection from B to A. 

---
Proof by case analysis:

There exists no surjection from B to A implies that $|B| < |A|$, and by the pigeon hole principle, there exists no injection from A to B

There exists a surjection from B to A implies that $|B| \ge |A|$, and therefore there exists $C \subseteq B, |C| = |A|$ which implies there exists an injection from A to B. The contrapositive of this statement also creates the implication backwards. Thus, this is an if and only if relationship.
