*Key Concepts:*
___

A tautology is a statement which is true for all possible arguments.

For example, $p \implies q$ may be true for a certain pair of p, q, but it may not be true for all sets of p, q in the domain of discourse. 

Practically: Sarah has a type of pet implies Jason has the same type of pet. 

If Sarah and Jason both have dogs, this is true.
However, if Sarah has a lizard and Jason does not, this is not true. So it is not a tautology.
