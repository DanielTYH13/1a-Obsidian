*Key Concepts:*
___

A tautology is a statement which is true for all possible arguments.

For example, $p \implies q$ may be true for a certain pair of p, q, but it may not be true for all sets of p, q in the domain of discourse. 

A good example is the following $\text{I ate breakfast today} \implies \text{I ate lunch today}$. This may be true for certain days, but false for others. So it may make sense to write this implication under certain premises, but it is not a tautology.

However, something like $\overline{P \wedge Q} = \overline{P} \vee \overline{Q}$ is a tautology, as it is true for any input P and Q. Thus, we can use an iff symbol $\overline{P \wedge Q} \iff \overline{P} \vee \overline{Q}$
