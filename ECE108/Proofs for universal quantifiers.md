*Key Concepts:*
___

For universal quantifier proofs, ie when you need to prove a claim for all elements within a set, the following proof methods are often very effective:

- A "forall" quantifier proof.
	- Proofs which logically deduct (such as contruction, implication, contradiction) from a base set of premises which contain a forall quantifier that applies to the entire set. Then the proof is true for all elements. 
- Proof by Induction
	- When you find yourself unable to craft a forall quantifier that is sufficient to deduct a proof, you can look to induction. Induction requires only something true (the induction assumption) about a finite element. Thus, if you are able to find that premise for a single element, you can prove an infinite amount of elements from it.
