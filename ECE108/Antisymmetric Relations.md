*Key Concepts:*
___

A relation is antisymmetric if the only symmetric pairs in the relation are ones which map to equivalent values. 

$\forall \langle x, y \rangle \in A^2, \langle x, y \rangle \in R \wedge \langle y, x \rangle \in R \implies x = y$

Note that this definition does not require two ordered pairs of the same values. The set {(1, 1)} is antisymmetric.
