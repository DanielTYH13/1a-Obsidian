*Key Concepts:*
___

A set is "finite" if its cardinality is an element of the natural numbers. It is "infinite" if otherwise.

Thus, the definition of finiteness:

A set S is finite if and only if there exists a bijection from S to $\mathbb{N}_{n}$. ([[Cardinality]])

---
Finiteness as an injection.

The set S is finite if you can construct an injection to $\mathbb{N}_n$.

You can then construct another function which "collapses" the injection into a bijection to $\mathbb{N}_{n'}$, yielding $h(x) = g(f(x))$ is bijective to $\mathbb{N}_n$, which is then finite by the above definition.

A function g(x) exists for all sets $R_f$. An example is the ordering function, which maps $R_f$ to $\mathbb{N}_n$ based on the size of each f(x).
