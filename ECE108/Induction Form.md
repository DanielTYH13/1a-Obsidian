*Key Concepts:*
___

When you encounter a problem which:

- Asks to prove a claim for ALL terms which depend on elements of a set, where each element can be expressed incrementally wrt another. 
- Has some tangible case which you can prove the claim for individually

Then induction will often work. Because the question is formatted in a way that asks for the truth of all elements, and you can express elements incrementally, this reduces the "complexity" or "significance" of the proof from proving directly to forall to just proving from on element to another, assuming the previous element is true.

Example:

Prove $n^3 -4n +6$ is divisible for all n

Prove $\frac{1}{1\cdot3} + \frac{1}{3\cdot5} + \cdots + \frac{1}{n(n+2)} = \frac{n+1}{2(n+2)}$ for all positive odd integers n.
