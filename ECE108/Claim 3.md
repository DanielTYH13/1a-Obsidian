*Key Concepts:*

$p \implies q \iff p \vee r \implies q \vee r$

Proof by case analysis:

$p = F, r = F \implies$ the implication is true
$p = T \implies q = T \implies$ the implication is true
$r = T \implies q \vee r = T \implies$ the implication is true
$p = T, r = T \implies q \vee r = T \implies$ the implication is true.
