*Key Concepts:*
___

A probability function maps some set of events in the powerset of the sample space, S, to a real number. 

Ie, $s \in A \subseteq \mathscr{P}(S)$, where S is the set of all possible events, and s is an individual event within a subset of events. 

The probability function $Pr\{A\}$ must satisfy the axioms:

$\forall A \subseteq S, Pr\{A\} \ge 0$
$Pr\{S\} = 1$

---
For mutually exclusive events:

$Pr\{A_{1} \bigcup A_{2} \bigcup A_{3} \ldots \} = Pr\{A_{1}\} + Pr\{A_{2}\} + \cdots$

It also follows that since all events are mutually exclusive, then we can represent each event as a set of cardinality 1, for which it then follows that 

$Pr\{A\} = \displaystyle \sum_{s \in A} Pr\{s\}$
