*Key Concepts:*
___

A function is surjective if $R_{f} = CD_f$ (If the range of f is equal to the codomain of f). 

Ie it is surjective if it maps to the entirety of its codomain.

---
Existance of Surjectivity

There exists a surjective function $S \to R$ if and only if there exists an injective function $R \to S$

The only way an injective function $R \to S$ does not exist is if |S| < |R|. Thus, we have that if an injective funciton exists $|S| \ge |R|$ and thus there exists a surjective function $S \to R$.
