*Key Concepts:*
___

A function is surjective if $R_{f} = CD_f$ (If the range of f is equal to the codomain of f). 

Another way to define it is if all elements in the codomain have a preimage in the domain:

$\forall x\in D_{c}, \exists x_{0}\in D_{0} | f(x) = y$

(A function maps to all elements in a codomain $\iff$ all elements in the codomain can be represented as the mapping of a preimage in the domain. (Does there exists an x in the domain that, when mapped by f(x), is y for all y?))

---
Existance of Surjectivity

There exists a surjective function $S \to R$ if and only if there exists an injective function $R \to S$

The only way an injective function $R \to S$ does not exist is if |S| < |R|. Thus, we have that if an injective funciton exists $|S| \ge |R|$ and thus there exists a surjective function $S \to R$. 

---
Corollary:

If there exists a surjective function from A to B, then $|A| \ge |B|$
