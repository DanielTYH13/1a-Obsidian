*Key Concepts:*
___

A function is injective if it is "one to one". In other words, for any $x \ne y \in D_{f} \implies f(x) \ne f(y)$ which is equivalently $f(x) = f(y) \implies x = y$

---
Existance of Injectivity:

There exists an injective function $S\to R$ if and only if there exists a surjection $R \to S$. 

You can imagine that the only way a surjection from $R \to S$ does not exist is if $|R| < |S|$. Thus, if a surjection exists, then $|R| \ge |S|$ and thus an injection $S \to R$ exists.

---
Corollary

If there exists an injective function A to B, then $|A| \le |B|$
