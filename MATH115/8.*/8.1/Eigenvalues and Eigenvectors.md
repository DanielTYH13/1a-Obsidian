*Key Concepts:*
___

- Given a matrix $A\in M_{nxn}(\mathbb{R})$, an 
	- Eigenvector $\vec{x}$ is any vector that fulfills $A\vec{x} = \lambda \vec{x}$, or in other words, it outputs a scalar multiple of itself.
	- Eigenvalue $\lambda$ is the scalar value for a corresponding eigenvector s.t. $\frac{A\vec{x}}{\lambda} = \vec{x}$, or $A\vec{x} = \lambda \vec{x}$
	- This naturally extends to transformations.
