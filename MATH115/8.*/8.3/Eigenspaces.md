*Key Concepts:*
___

- An Eigenspace is the set of all solutions to the system $(A-I\lambda) = \vec{0}$.
	- In other words, it is all the corresponding eigenvectors for a given eigenvalue. 
	- The eigenspace of A corresponding to $\lambda$ is $E_{\lambda}(A) = Null(A - I \lambda)$

- Let u be the set that fulfills $(A-I\lambda) = 0$.
	- u = $null(A - I\lambda)$
