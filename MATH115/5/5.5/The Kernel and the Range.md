*Key Concepts:*
___

- Definition: Given $T: \mathbb{R}^n \to \mathbb{R}^m$ be a linear transformation, the:
	- Kernel: $Ker(T) = \{\vec{x}\in \mathbb{R}^n  | T(\vec{x}) = 0\} \subseteq \mathbb{R}^n$
	- Range: $Range(T) = \{ T(\vec{x})  | \vec{x} \in \mathbb{R}^n \} \subseteq \mathbb{R}^n$
		- To test for range, simply put it into RREF and try to find a solution, this will show you if there is a vector in $\mathbb{R}^n$ that points to that 'output' vector.
			- If inconsistent, not in the range. 
![[Pasted image 20251203141950.png|500]]

- Theorem: Given T be a linear transformation, then:
	- $Ker(T) = Null([T])$
		- Thus, $Ker(T) \subseteq \mathbb{R}^n$
		- Proof left as an exercise
	- $Range(T) = Col([T])$
		- Thus, $Ker(T) \subseteq \mathbb{R}^m$
		- Proof left as an exercise
