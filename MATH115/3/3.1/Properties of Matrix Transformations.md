*Key Concepts:*
___

- Let $A \in M_{mxn}(\mathbb{R})$. Then the matrix transformation $f_{A}: \mathbb{R}^n \to \mathbb{R}^m$ is defined by $f_{A}(\vec{x})=A\vec{x}$ and has the following properties:
	- $f_{A(\vec{x}}+\vec{y}) = f_{A}(\vec{x}) + f_A(\vec{y})$
	- $f_A(c\vec{x}) = cf_A(\vec{x})$.
- As these properties hold for all forms $A\vec{x}$, then all matrix transformations are [[Archive/1A/MATH115/3./3.1/Linear Transformations]].
