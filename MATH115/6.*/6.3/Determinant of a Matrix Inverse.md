*Key Concepts:*
___

- Theorem: $\mathrm{det}(A^{-1}) = \frac{1}{\mathrm{det}(A)} = (\mathrm{det}(A))^{-1}$
	- Thus, if det(A) $\ne$ 0, which is apparent as $A^{-1}$ exists, then $A^{-1}$ is also invertible - namely, the inverse is A itself. 
	- Proof left as an exercise

- Given A is invertible and k is a positive integer, $A^{-k} = (A^{-1})^k$:
	- $det(A^{-k}) = det((A^{-1})^k) = det(A^{-1})^k = det(A)^{-k}$
	- $det(A^0) = det(I) = 1 = (det(A))^0$: Note how det(A) must not be 0 to be valid. 
- Thus, $det(A^k) = det(A)^k$ for any integer k, but A must be invertible if k <= 0.
	- A must be invertible as:
		- -k indicates it is inverted A
		- Condition for $det(A^0) = (det(A))^0$
