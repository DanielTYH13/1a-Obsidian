*Key Concepts:*
___

- Rank nullity theorem says that for a matrix $A\in M_{mxn}$, $Rank(A) + Nullity(A) = n$
	- This makes sense, as solving for the nullity, you have:
		- dim(Null(A)), where Null(A) is the set of vectors which satisfy A$\vec{x} = \vec{0}$. 
		- To find the general solution to this set of vectors, carry the augmented matrix $[A|\vec{0}]$ to RREF, and take the solution.
		- This solution will have n parameters, which are LI. thus, the Nullity(A) = # of free variables. 

- We use the nullity, as this will allow the system to be consistent if there are free variables.
